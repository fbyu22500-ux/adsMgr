【 Windows 电脑 】
  第 1 步：双击「安装环境.bat」
           —— 自动安装 Python 和 Excel 组件（需联网，约 1~3 分钟）
           —— 装完自动打开浏览器进入系统
  第 2 步：账号 admin / 密码 admin123456 登录
  第 3 步：立刻修改密码（右上角头像菜单）

  以后每天使用：双击「启动.bat」就够了（不用再装环境）。

【 Mac 电脑 】
  双击「安装环境.command」时若弹出：
  “Apple无法验证…是否包含可能危害Mac安全…的恶意软件”
  —— 这是 macOS 对【所有从网上下载、未经苹果公证】的程序的一刀切拦截，
      不代表检测到了病毒。用下面任意一种方法放行即可（10 秒）：

  ── 方法一（推荐）：清除“隔离标记”，一次搞定 ──
   1. 按 Command + 空格，输入「终端」，回车打开终端
   2. 复制这一行，粘贴进终端，按回车：
        xattr -cr ~/Downloads/FB广告账户管理系统
      （文件夹不在“下载”里？把文件夹从访达直接拖进终端窗口，路径会自动填上）
   3. 回到文件夹，双击「安装环境.command」→ 正常打开 ✓

  ── 方法二：系统设置里放行 ──
   双击报错后：打开 系统设置 → 隐私与安全性 → 拉到下面“安全性”区域 →
   点【仍要打开】→ 输入开机密码 → 再双击一次即可
   （旧版 macOS：直接右键点文件 → 打开 → 再点“打开”）

  ── 方法三：不装环境，用终端直接跑 ──
   终端里逐行执行：
        cd ~/Downloads/FB广告账户管理系统
        python3 server.py
   然后浏览器打开 http://localhost:8765
   （若提示没有 python3，先按方法一放行后双击「安装环境.command」）

  以后每天使用：双击「start.command」就够了。

【 常见问题 】
  · Windows 双击一闪就没了？→ 打开“命令提示符”，把「安装环境.bat」拖进去回车，能看到具体提示。
  · 端口被占用？→ 双击「启动.bat 3000」换个端口。
  · Excel 导入用不了？→ 联网重新双击「安装环境」重装一次组件。
  · 数据都在「data」文件夹；用 系统→设置→数据维护 定期备份，换电脑整个文件夹拷走。

【 安全提醒 】
  admin/admin123456 是演示密码，第一次登录务必修改！
  本系统仅建议在本机或公司内网使用，不要直接暴露到公网。
